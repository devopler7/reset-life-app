# Reset — Life Dashboard v2.5.0

A local-first iPhone-friendly PWA for running the day, weekly planning, university, money, fitness, car and personal projects without turning life into a complicated productivity system.

## v2.5 highlights

- **Money remaining:** a prominent card shows exactly how much of the total monthly allocation is still available before the plan is reached, or how far over the allocation spending has gone.
- **Monthly money trend:** last six months of logged spending are shown on one scale. Monthly allocation markers begin saving from this version forward.
- **More scroll memory:** open Gym, Health, Car, Projects or Reset Plan, then go back and Reset returns to the exact place you were on the More page.
- **Late sleep logging:** the sleep item has a dedicated actual-time log. Sleeping after midnight can be recorded against the intended night instead of being lost when the calendar day changes.
- **Last-night reminder:** if yesterday's sleep was never marked, Today offers a small reminder to log it later.
- All v2.4 features remain, including flexible task movement, quick current-task completion, edit/delete history, progress comparisons, gym PRs, health weight tracking and car maintenance history.

## Data
Reset has no account or server. Data stays on the device/browser with localStorage plus an automatic IndexedDB copy, unless you export a JSON backup. Browser data can still be removed if website data is cleared or the web app is deleted.

## Update
Upload all files inside this folder to the existing GitHub Pages repository, commit to `main`, wait for deployment, then fully close/reopen the Home Screen app. Settings should show **v2.5.0**.
