# Reset — Life Dashboard v2.3.0

A personal iPhone-first PWA for daily planning, weekly schedule, university, money, progress, gym, car and projects.

## v2.3 polish
- Prevents iOS double-tap zoom on normal app interactions while retaining normal page panning/pinch behavior where supported.
- Replaces font-symbol navigation icons with consistent inline SVG icons.
- Improves mobile tap targets and spacing.
- Keeps scroll position when checking off timeline tasks.
- Shows a subtle one-time **Day Complete** celebration when every planned task is done.
- Shows **Recovery Complete** if fixed events were missed but every remaining actionable task is finished.
- Settings displays v2.3.0.

Data remains local-first with localStorage + IndexedDB redundancy and JSON export/import.
