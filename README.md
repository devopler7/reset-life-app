# Reset — Life Dashboard v2.4.0

A local-first iPhone-friendly PWA for running the day, weekly planning, university, money, fitness, car and personal projects without turning life into a complicated productivity system.

## v2.4 highlights

- **Current task controls:** mark the active/overdue task done directly from the top of Today.
- **Flexible schedule:** move a flexible item to another time, swap it with another flexible item, restore its planned time, or move it to tomorrow. Classes, wake-up/morning essentials and sleep stay locked.
- **End-of-day cleanup:** keep, move tomorrow, or drop unfinished flexible items.
- **Editable history:** edit/delete spending, gym exercise logs, body weight, fuel, car maintenance, project sessions and weekly reviews. Workout-day logs can be removed.
- **Progress:** 7-day / 30-day / all-time stats, this-week vs last-week summary, last-30 vs previous-30 comparison, streaks and achievements.
- **Gym:** strength charts and personal bests.
- **Health:** intentionally simple body-weight tracking only.
- **Car:** fuel plus maintenance history.
- **Data safety:** localStorage + automatic IndexedDB copy + JSON export/import.

## Data
Reset has no account or server. Data stays on the device/browser unless you export a JSON backup. Browser data can still be removed if website data is cleared or the web app is deleted.

## Update
Upload all files inside this folder to the existing GitHub Pages repository, commit to `main`, wait for deployment, then fully close/reopen the Home Screen app. Settings should show **v2.4.0**.
