RESET v3.6.0 TEST REPORT

Release focus
-------------
This patch was tested specifically around the new editable Plan Day workflow, Task/Reminder creation, intentional overlaps, cancelled fixed events, collision handling and responsive iPhone layouts.

Static/runtime checks
---------------------
- app.js passes Node.js syntax validation.
- App booted in a Chromium browser harness with no uncaught JavaScript errors.
- Version wiring confirmed as v3.6.0 in app code, HTML, VERSION.txt and service-worker cache assets.

Targeted browser regression suite: 15/15 passed
------------------------------------------------
- Today opens the Task / Reminder picker.
- Reminder saves with non-blocking semantics.
- Reminder badge renders on the timeline.
- Needs attention identifies the exact overlapping item names.
- Intentional fixed-event overlap suppresses false attention.
- A reminder overlapping a class does not create an overlap issue.
- Plan Day rows are actionable rather than read-only.
- Plan Day exposes Add for one-off items/reminders.
- Flexible Plan Day items expose move/swap controls.
- Fixed Plan Day items expose cancel-for-day controls.
- Cancelled fixed events no longer block a move.
- Restored fixed events protect their original time again.
- Back-to-back boundaries are not misclassified as overlaps.
- No browser console/page errors occurred.

Plan Day action suite: 9/9 passed
--------------------------------
- Plan Day move persists a manual time override.
- Saving a move returns to Plan Day.
- Cancel-for-day state persists.
- Cancelled items expose Restore.
- Restore clears the cancellation state.
- A reminder added from Plan Day saves correctly.
- Adding an item returns to Plan Day.
- Stress case with 200 overlapping reminders: zero reminder items were scheduled, moved, marked unplaced or reported as conflicts.
- No browser errors occurred during the action suite.

Responsive checks: 12/12 passed
-------------------------------
Today, Add Item, and Plan Day were checked at 320, 375, 390 and 430 px viewport widths. No horizontal overflow was detected and no page errors occurred.

Manual visual inspection
------------------------
- Task / Reminder picker reviewed at 390 px.
- Plan Day conflict panel and actionable item rows reviewed at 390 px.
- Reminder and overlap controls use the existing Reset dark-card/icon language.

Limitations
-----------
Automated browser testing cannot perfectly reproduce physical iPhone Home Screen/Safari behavior, touch latency, keyboard behavior, or GitHub Pages deployment caching. A short real-device smoke test after deployment is still recommended.
