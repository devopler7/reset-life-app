RESET v3.3.0 TEST REPORT
========================

Scope
-----
This release was tested as a migration/update from Reset v3.2.0 and as a clean install state. Testing focused especially on the new gym system, wake/sleep anchors, future-day rebuilding, missed/cancelled items, the Sleep Life Tool, Progress, iPhone layouts, Arabic RTL, large histories and data preservation.

Deterministic regression suite
------------------------------
107/107 checks passed.

Covered examples include:
- v3.2 -> v3.3 state migration and preservation of existing gym logs
- exact 10-exercise Full Body defaults
- Upper Body / Lower Body defaults and Custom workout behavior
- all four workout modes only
- quick weight/set/rep logging
- replacing the same exercise log inside one active workout instead of duplicating it
- actual kg / sets / reps displayed in an active workout
- Finish Workout and Cancel Workout confirmation flows
- complete multi-exercise gym history
- Upper Body / Lower Body / Core personal-best grouping
- exercise metadata and muscle-group migration
- one-day wake and sleep overrides without changing recurring defaults
- sleep after midnight assigned to the previous night
- late wake marking earlier flexible items missed
- restoring flexible missed items
- fixed/cancelled class handling
- permanent Wake / Sleep anchors cannot be deleted
- future-day rebuilding and sleep remaining the final anchor
- Other task category
- Sleep target/history calculations
- Perfect Week achievement
- Progress card/icon alignment
- Arabic RTL smoke testing
- widths 320, 390, 430 and 760 px with no tested horizontal overflow
- repeated rendering of all major screens with no uncaught JavaScript errors

Additional edge-case verification
---------------------------------
7/7 focused checks passed.

Included:
- deleting an exercise and Undo restoring the exercise and its workout-preset membership
- early one-day sleep time automatically moving a late flexible item before sleep so Sleep remains last
- Forearm/Trap secondary muscle metadata on pulling and rear-delt work

Known testing limitation
------------------------
The test environment can emulate iPhone-sized browser layouts but is not a physical iPhone running Safari as a Home Screen PWA. The final touch behavior, iOS keyboard behavior and Apple Home Screen cache behavior should therefore still be checked on the user's actual iPhone after deployment.
