RESET v2.2.0 - START HERE

UPDATING YOUR EXISTING GITHUB PAGES APP

1. In your current Reset app, Settings -> Export backup once before updating.
2. Unzip this download.
3. Open the life-reset-app folder.
4. Open your existing GitHub repository: reset-life-app.
5. Add file -> Upload files.
6. Drag EVERYTHING inside life-reset-app into the repository, including icons.
7. Commit directly to main.
8. Wait around 1-3 minutes for GitHub Pages.
9. Fully close Reset on your iPhone and reopen it.
10. Open Settings and confirm App version says v2.2.0.

You do NOT need to remove the Home Screen icon or reinstall the app.
Your v2.1 data should migrate automatically.
