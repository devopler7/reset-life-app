RESET v2.3.0 UPDATE

1. In your current Reset app, open ••• > Export backup once before updating.
2. Unzip this package.
3. Open the life-reset-app folder.
4. In your existing GitHub reset-life-app repository choose Add file > Upload files.
5. Upload EVERYTHING inside life-reset-app, including the icons folder.
6. Commit directly to main.
7. Wait 1–3 minutes for GitHub Pages.
8. Fully close Reset on iPhone and reopen it.
9. Open ••• and confirm App version says v2.3.0.

You do not need to remove or re-add the Home Screen app.
