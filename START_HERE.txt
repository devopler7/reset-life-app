RESET v3.4.0 — PERSONAL EDITION

Before updating:
1. Open Reset -> Settings -> Export backup.

Update GitHub Pages:
2. Open your reset-life-app GitHub repository.
3. Upload ALL files/folders inside this life-reset-app folder to the repository root.
4. Commit the upload and wait until the newest GitHub Pages deployment has a green check.
5. Fully close the Reset Home Screen app and reopen it.
6. Open Settings and confirm App version says v3.4.0.

If Safari/Home Screen still shows an older version, refresh the GitHub Pages website once in Safari, then fully close and reopen Reset.

Your existing local Reset data is migrated automatically. Keep the exported JSON backup until you have checked the update.
