RESET v3.0.0 — PERSONAL DESIGN EDITION

1. In your current Reset app, open Settings and Export backup once.
2. Unzip this package.
3. Open the life-reset-app folder.
4. Open your existing reset-life-app GitHub repository.
5. Choose Add file → Upload files.
6. Drag EVERYTHING inside life-reset-app into GitHub, including the icons folder.
7. Commit directly to main.
8. Wait about 1–3 minutes for GitHub Pages to deploy.
9. Fully close Reset on your iPhone and reopen it.
10. Open Settings and confirm App version says v3.0.0.

If the old design remains, open your GitHub Pages link once in Safari, refresh it, then fully close/reopen the Home Screen app.

Your v2.6 data is designed to migrate automatically. The exported backup is only a safety copy.

LANGUAGE
Settings → Language → English or 🇸🇦 العربية. Arabic switches the interface to RTL.

LOCAL ONLY
Reset v3.0 has no accounts, AI, analytics, ads, cloud database, currency API, or other external app services. Your app data stays in local browser storage, with the existing local IndexedDB backup copy and manual JSON export.
