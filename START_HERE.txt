RESET v3.3.0 — PERSONAL EDITION

Update your existing GitHub Pages app:
1. Export one backup from Reset first.
2. Upload everything inside this life-reset-app folder to the existing reset-life-app GitHub repository.
3. Commit to main and wait for GitHub Pages to deploy.
4. Fully close Reset on iPhone and reopen it.
5. Settings should show v3.3.0.

If the Home Screen app still shows an older version, open the GitHub Pages URL in Safari, refresh once, then fully close and reopen Reset.

All data stays local on your device.
