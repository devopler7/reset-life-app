HOW TO UPDATE GITHUB PAGES
1. Download and unzip Reset_Life_Dashboard_v2.1_FINAL.zip.
2. Open the life-reset-app folder inside it.
3. Open your existing reset-life-app repository on GitHub.
4. Click Add file -> Upload files.
5. Drag ALL files inside life-reset-app into GitHub, including the icons folder.
6. GitHub will show the existing files being replaced.
7. Commit directly to the main branch.
8. Wait around 1-3 minutes for GitHub Pages to redeploy.

ON IPHONE
1. You do NOT need to remove or re-add the Home Screen app.
2. Fully close Reset from the iPhone app switcher.
3. Reopen Reset.
4. If it still looks old, open your normal GitHub Pages URL in Safari, refresh once, then fully close and reopen Reset again.
