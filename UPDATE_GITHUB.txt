RESET v3.6.1 UPDATE

1. Export a backup from Reset.
2. Unzip this package.
3. Open the life-reset-app folder.
4. Upload its CONTENTS to the root of your existing GitHub repository.
5. Commit the changes.
6. Wait for the newest Pages deployment to show a green check.
7. Fully close and reopen the Home Screen app.
8. Verify Settings -> App version = v3.6.1.

If the website says v3.6.1 but Home Screen is still older, close it from the app switcher, refresh the Pages URL once in Safari, then reopen Reset.
