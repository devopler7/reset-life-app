RESET v3.0.0 UPDATE

1. Export one backup from the current app.
2. Open your existing GitHub reset-life-app repository.
3. Add file > Upload files.
4. Upload EVERYTHING inside this life-reset-app folder, including icons.
5. Commit to main.
6. Wait 1–3 minutes for GitHub Pages.
7. Fully close Reset on iPhone and reopen it.
8. Open Settings and confirm v3.0.0.

If the old version remains, open the Pages URL in Safari once, refresh it, then fully close/reopen the Home Screen app.
