RESET v3.6.3 — GYM UPDATE

1. Export a fresh JSON backup from your current Reset app.
2. Unzip this package and open life-reset-app.
3. Upload EVERYTHING INSIDE life-reset-app to the ROOT of your existing GitHub Pages repository, including the icons folder.
4. Commit the upload and wait for the Pages deployment to finish.
5. Close and reopen Reset. Apply Update ready if offered.
6. Open Settings and confirm v3.6.3.

Your existing on-device data upgrades automatically. No JSON import is needed. Keep the existing website address so Reset can keep using its stored data.

NEW IN GYM
- Start Workout stays active until you finish or cancel, including after midnight or reopening the app.
- An overnight workout and its exercise logs belong to the date on which it started.
- The active workout shows elapsed time. Finishing stores the actual start, finish and duration.
- Gym > History > Workout Days shows duration per day. Details shows individual workout times and exercise sets. Multiple workouts on one date retain their separate times and a combined total.
- Exercise logging shows LAST TIME with the previous working sets and a Use last workout button.
- Each set has its own weight and reps. Add working sets or warm-ups independently. Copy first working set to all working sets speeds up identical sets.
- Warm-ups remain in history but do not enter strength charts, PRs or strength-gain achievements.
- Partial exercise entries are saved automatically on this device. Reopen that exercise to continue. Explicitly finishing/cancelling discards unfinished drafts after a warning.

Older aggregate logs are retained. You can edit a previously logged warm-up and change its set types to Warm-up. Reset does not guess which old sets were warm-ups.

Duration is measured from Start Workout to Finish workout, including rests and time with the app closed. Older workouts have no saved finish times and therefore show Duration not recorded.

If you still see an older version, refresh the existing Pages URL in Safari once, then close and reopen Reset.

The package contains app code only. It does not include your private JSON backup. Local regression checks passed. Physical iPhone layout and touch behaviour were not tested here. See TEST_REPORT.txt.
