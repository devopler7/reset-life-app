RESET v3.4.0 UPDATE

1. Export a Reset JSON backup first.
2. Upload every file/folder inside life-reset-app to the ROOT of the existing GitHub repository.
3. Commit the upload.
4. Wait for GitHub Pages deployment to finish with a green check.
5. Fully close and reopen Reset on iPhone.
6. Verify Settings -> App version = v3.4.0.

Do not create a nested life-reset-app folder in the repository. The repository root should directly contain index.html, app.js, styles.css, service-worker.js and the icons folder.
